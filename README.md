# E-Commerce-Online Shopping(Resposive Frontend)
 • E-Commerce web app is build using React for a fast, modular, and interactive UI, ensuring seamless navigation
   and dynamic updates without page reloads.
 • TailwindCSS is used for a sleek, responsive design with utility-first styling, enabling rapid development and a
   modern aesthetic across all devices.
